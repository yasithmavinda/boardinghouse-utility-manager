Help & Operator User Manual

Learn how billing cycles work, how to split utility bills, and manage roommates rosters

1. System Initialization & Registry

  • 1.1 System Configuration Parameters Navigate to the **Settings** tab. Set the Default monthly contribution per boarder, select LKR or preferred currency, specify the Operational Financial Year, and customize parameters. These configurations act as global variables for computations.
  • 1.2 Roommates Registry Directory Open the **Roommates Registry** tab. Use the "Add Roommate" button to add boarders. Toggling status to Active makes them count toward monthly splits. Toggle to Inactive when they leave. Room details and contact parameters propagate to dropdown selectors.

2. Data Entry & Billing Operations

  • 2.1 Recording Monthly Roommate Payments Navigate to the **Rent & Collections** page. Click "Log Roommate Payment". Select the appropriate billing month and roommate profile. Standard monthly contribution is pre-filled, but custom extra, partial, or advance amounts can be input. Payment Date determines status: if paid *after* the 10th of the month, status automatically flags as **Late**. If unpaid, status flags **Not Paid**. If partially paid, it flags **Partial**.
  • 2.2 Logging Monthly Utility Invoices Open the **Utility Bills Log** page. Click the "Edit/Log" icon for the corresponding calendar month. Fill out water, electricity, internet, gas, and cleaning totals. The system automatically computes total monthly expenses and updates metrics.
  • 2.3 Recording Miscellaneous Cash Disbursements Log ad-hoc boarding costs (like plumbing fixes, broken locks, or kitchen bulb replacements) on the **Misc Expenditures** page. Categorize, log the paid amount, specify date, vendor paid to, and reference details. The system uses the transaction date to calculate totals for the respective billing month.

3. Analytics, Reports Binder & Backup Maintenance

  • 3.1 Performance Summaries & Cash Flow Trends The **Monthly Summary** sheet aggregates all collection sums vs. total expenditures (utilities + misc) to compute cash flow. The Carry Forward recursively rolls cash surpluses or deficits forward month-over-month. The **Dashboard** plots these visual trends in six responsive charts (Collections vs. Expenses, status proportions, utility shares, roommate outstanding, flow margins, and cumulative balances).
  • 3.2 Visual Payment Tracker Matrix The **Payment Status Matrix** provides an annual grid showing colored indicators representing payment statuses by roommate and month. You can click on any grid dot to instantly log or edit roommate payments.
  • 3.3 Exporting Standardized A4 PDF Reports Open the **Reports Binder** tab. Click a report title in the report index to compile tables dynamically. Click "Print to A4 / Save PDF" to access the print layout. Print styles automatically format the page, hide the sidebar, and resize columns to crisp standard A4 portrait pages.
  • 3.4 Offline Data Security & Restore Actions Since the system runs locally inside browser sandbox LocalStorage, ensure database security by exporting database backups frequently. Go to **Settings** and click "Export Database (.JSON)" to save copy backups. If you switch devices, open settings, click "Import Database (.JSON)", and choose your backup file. To test out the system's capabilities instantly, click the "Seeding Mock Demonstration Data" button to auto-populate tables.
